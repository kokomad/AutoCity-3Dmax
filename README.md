# 🚘 AutoCity 3D Launcher

لانشر جوال تفاعلي ثلاثي الأبعاد يعمل بالويب ومُهيأ للنشر المباشر على **GitHub Pages** أو التحويل إلى تطبيق Android APK.

## ✨ المميزات الرئيسية
- **واجهة رئيسية نقية وحيوية:** مدينة ثلاثية الأبعاد تتحرك فيها السيارات على الطريق السريع، وتحمل كل سيارة اسم وأيقونة تطبيق لفتحه بلمسة واحدة.
- **قائمة إعدادات شاملة للتخصيص:**
  - تبديل مشاهد المدينة (الليل القمري الأزرق، الغروب الناري، النهار المشرق).
  - تغيير زوايا الكاميرا ثلاثية الأبعاد (مطاردة قريبة، بانوراما علوية، مستوى الشارع).
  - التحكم بسرعة حركة المرور أو تفعيل وضع اصطفاف جميع السيارات بضغطة زر.
  - إضافة سيارات وتطبيقات مخصصة بروابط ويب أو أوامر Android `intent://`.
- **دعم PWA كامل:** يتضمن أيقونة التطبيق الرسمية وملف `manifest.json` و`sw.js` للعمل كتطبيق مستقل على الجوال.

## 🚀 طريقة الرفع والتشغيل على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub**.
2. ارفع جميع محتويات هذا المجلد (`index.html`, `manifest.json`, `sw.js`, ومجلد `assets`).
3. انتقل إلى **Settings** داخل المستودع ثم اختر **Pages**.
4. من قسم **Branch** اختر `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. سيظهر لك رابط التشغيل المباشر للانشر خلال ثوانٍ.
